# Campo Minado em C 💣

Projeto desenvolvido em linguagem C como atividade prática acadêmica, com foco em alocação dinâmica de memória, manipulação de matrizes bidimensionais e modularização de código.

## 📚 Sobre o projeto
Este projeto consiste em uma implementação do clássico jogo **Campo Minado**, executado no terminal.

O objetivo principal da atividade foi aplicar conceitos de **alocação dinâmica de matrizes utilizando vetor de ponteiros**, além de reforçar lógica de programação, manipulação de memória e organização modular do código em C.

O jogo permite ao usuário selecionar diferentes níveis de dificuldade, gerando automaticamente um campo minado com posições aleatórias de minas.

## 🚀 Tecnologias utilizadas
- Linguagem C
- `stdio.h`
- `stdlib.h`
- `time.h`

## 🎯 Objetivos de aprendizado
Durante o desenvolvimento deste projeto, pratiquei:

- Alocação dinâmica de memória com `malloc()` e `free()`
- Manipulação de matrizes bidimensionais dinâmicas
- Uso de ponteiros
- Modularização com funções
- Validação de entrada do usuário
- Estruturas condicionais e laços de repetição
- Geração de números aleatórios
- Desenvolvimento de lógica aplicada a jogos

## ⚙️ Funcionalidades
- Escolha entre três níveis de dificuldade:
  - Fácil → 10x10 (3 minas)
  - Médio → 20x20 (6 minas)
  - Difícil → 30x30 (9 minas)

- Geração aleatória das minas
- Cálculo automático da quantidade de minas vizinhas
- Validação de coordenadas inválidas
- Detecção de coordenadas repetidas
- Sistema de vitória e derrota
- Revelação completa do campo ao final da partida
